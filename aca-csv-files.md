# Two Datasets Generated Using Agentic AI
These two datasets were created by using agentic AI to bulk process handwritten text recognition using both Gemini and Claude. At the time, in March 2026, the agentic AI application I used was OpenClaw (no longer recommended). If you are interested in setting up an agentic AI bulk processm, as of October 2026, I recommend Claude Cowork as the best option (although it might be very expensive).
